# Сменный график

Сайт для планирования двух смен на 30 сотрудников с учётом ТК РК. Один файл `index.html`, без сборки и зависимостей (шрифты подгружаются с Google Fonts).

## Возможности

- Две смены: 9:00–18:00 (пн–пт) и 12:00–19:00 (пн–сб), воскресенье выходной.
- Смены меняются каждую неделю: группа A и группа B чередуются.
- Больничный сотрудника 2-й смены закрывает сотрудник 1-й смены (замена 12:00–19:00).
- Добавление, переименование, удаление сотрудников и перевод в другую смену.
- Отпуска и больничные по датам.
- Праздники РК с переносами отдельно для пятидневки и для 2-й смены (пн–сб), список праздников редактируется.
- Недельный и месячный график, подсчёт часов с проверкой нормы 40 часов в неделю.

## Запуск

Откройте `index.html` в браузере.

## Публикация на GitHub Pages

1. Создайте репозиторий и загрузите `index.html` и `README.md` в корень.
2. Откройте Settings → Pages.
3. В разделе Build and deployment выберите Source: Deploy from a branch, ветку `main` и папку `/ (root)`.
4. Через минуту сайт появится по адресу `https://<ваш-логин>.github.io/<имя-репозитория>/`.

## Данные

Сотрудники, отпуска, больничные и настройки хранятся в `localStorage` браузера. На другом устройстве или в другом браузере график будет начинаться с примера. Для общего хранилища нужен сервер или база данных.

## Что проверить вручную

- Список праздников заполнен по открытым источникам. Дату Курбан-айта на 2027 год и новую дату Дня Конституции добавьте на вкладке «Праздники и настройки».
- Между неделями (суббота 19:00 → понедельник 9:00) остаётся 38 часов отдыха. Сверьте с требованиями ТК РК к непрерывному еженедельному отдыху.
